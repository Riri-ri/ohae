# minifigma

**Дизайн-редактор, который всегда с тобой.**
Рисуй в браузере на телефоне и компьютере — без аккаунта и оплаты. Базовые инструменты,
готовые шаблоны и немного котиков.

Мини-версия Figma для набросков вне дома: базовый редактор фигур в браузере, на телефоне и
компьютере. Лёгкий, быстрый, открывается мгновенно.

## Для кого

Главный герой — дизайнер в пути: поймать идею, собрать черновик, когда полноценная Figma под
рукой недоступна. Также подойдёт новичкам и друзьям.

## Стартовая страница

Отдельный экран перед редактором, блоки по порядку:

1. Кнопка **«Скачать приложение»** — запускает установку PWA, один клик, без установщика.
2. Краткое описание.
3. Скриншоты — редактор и шаблоны.
4. Инструкция — как пользоваться.
5. Внизу — мем-котик и подпись «приятного пользования».

## Что внутри

- **Ваши работы** — редактор с несколькими работами «в процессе»: прямоугольники, эллипсы,
  перетаскивание, ресайз, слои, свойства, undo/redo (Ctrl+Z / Ctrl+Shift+Z), зум колесом и
  панорамирование пробелом. Всё хранится в `localStorage` по каждому проекту.
- **Предложения дизайнов** — готовые шаблоны (лендинг, мобильное приложение, постер, дашборд,
  логотип-кот). Открываются в редакторе как новая работа.

Для настроения, вторым планом:

- **Котики** — раздел для расслабона: мемные котики генерируются в браузере, понравившегося можно
  отправить на холст.
- **Курсор** — смена курсора на один из предложенных вариантов (лапа, кот, карандаш, сердце и др.).

Адаптировано под телефон: панель свойств выдвижная, вкладки и список работ скроллятся.

## Ограничения

- Работы хранятся только в этом браузере (`localStorage`), без аккаунта; между устройствами они не
  синхронизируются.
- Котики и AI-картинки требуют интернета — оффлайн доступны редактор и работы.
- Промпты для картинок и перевода уходят на сторонние серверы (см. «Сторонние сервисы»).
- Ранняя (бета) версия.

## Запуск

```
npm install
npm run dev
```

Сборка: `npm run build`, проверка типов: `npm run typecheck`.

## Сторонние сервисы

Генерация картинок (AI-картинки и котики) идёт через `image.pollinations.ai`; перевод промпта с
кириллицы — через `mymemory.translated.net`. Ключи не требуются, но промпт уходит на эти серверы.
