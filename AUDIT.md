пункты прошлого P0/P1 (хендлы ресайза, `scaleStart/scaleMove/scaleEnd` в возврате хука, зум на
`window`, перехват `Ctrl+колеса`, пробел в полях ввода, таймауты, `ResizeObserver`, `index.orig.html`,
`.env` в `.gitignore`, скрипт `typecheck`, favicon) подтверждены как исправленные — жалоб нет,
`npm run typecheck` и `npm run build` проходят. Ошибался только пункт про `main`; `addShape` теперь
возвращается из хука, но остаётся мёртвым (перенесён в P2).
